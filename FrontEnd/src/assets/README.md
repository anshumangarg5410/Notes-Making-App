# Asset Inventory & Clipart Organization — NoteNest

This directory organizes all illustrations, stickers, icons, and design references used across NoteNest.

## Directory Structure

```text
FrontEnd/src/assets/
├── landing/
│   ├── pencil-navbar-dark.png       # Realistic wooden pencil navbar for dark mode
│   ├── pencil-navbar-light.png      # Realistic wooden pencil navbar for light mode
│   ├── editor-preview-dark.png      # Floating NoteNest tablet editor UI with paper layers (dark)
│   ├── editor-preview-light.png     # Floating NoteNest tablet editor UI with paper layers (light)
│   ├── sticky-heart-dark.png        # Yellow sticky note with hand-drawn heart doodle
│   ├── binder-clip-dark.png         # Metal stationery binder clip
│   ├── paper-layer-dark.png         # Torn paper texture layer
│   ├── card-about-dark.png          # Illustrated card for About section (dark)
│   ├── card-about-light.png         # Illustrated card for About section (light)
│   ├── card-how-dark.png            # Illustrated card for How It Works (dark)
│   ├── card-how-light.png           # Illustrated card for How It Works (light)
│   ├── card-features-dark.png       # Illustrated card for Features highlight (dark)
│   ├── card-features-light.png      # Illustrated card for Features highlight (light)
│   ├── footer-cta-dark.png          # Newsletter CTA banner with glowing borders (dark)
│   ├── footer-cta-light.png         # Newsletter CTA banner with paper texture (light)
│   ├── footer-ribbon-dark.png       # Bottom desk torn paper ribbon (dark)
│   ├── footer-ribbon-light.png      # Bottom desk torn paper ribbon (light)
│   ├── notenest-glow-logo-dark.png  # NoteNest glowing logo mark (dark)
│   └── notenest-glow-logo-light.png # NoteNest logo mark (light)
│
├── landingDark.png                  # Master dark theme clipart & mockup asset sheet
├── landingLight.png                 # Master light theme clipart & mockup asset sheet
├── footerDark.png                   # Master dark theme footer illustration asset sheet
└── footerLight.png                  # Master light theme footer illustration asset sheet
```

## Source & Processing
- **Source**: User-provided dark & light theme design mockups and clipart packs.
- **Processing**: Cropped at pixel boundaries with alpha channel preservation, maintaining high-resolution proportions, paper textures, and ambient glow effects.
