# Contact Page Assets

This directory contains illustrations and visual assets used specifically for the NoteNest Contact page (`/contact`), cropped and prepared from the design reference.

## Assets Inventory

- `envelope-message-glow.png`: Floating glowing purple 3D envelope with letter and flight path paper plane with alpha transparency, optimized to float smoothly over the fixed landing background.
- `envelope-message-dark.png`: The original cropped high-fidelity glowing envelope illustration with ambient dark purple illumination.

## Source

Cropped and optimized directly from the user-provided Contact page design reference.
