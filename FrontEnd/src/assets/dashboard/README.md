# NoteNest Dashboard Assets

This directory contains the illustrations, icons, and visual assets used by the NoteNest Dashboard workspace.

## Directory Assets

- `desk-illustration.png`: Desk workspace illustration featuring a laptop with NoteNest logo, ambient purple lighting, books, and desk plant.
- `desk-illustration-feathered.png`: Seamlessly feathered alpha version of the desk workspace illustration for the Welcome banner.
- `upgrade-pro-icon.png`: Stacked purple document sheets illustration for the Upgrade to Pro card.
- `upgrade-pro-icon-clean.png`: Alpha-isolated transparent version of the Upgrade to Pro illustration.
- `editor-desk-dark.png`: High-resolution dark desk illustration.
- `editor-desk-light.png`: High-resolution light desk illustration.
- `sidebar-quote-dark.png`: Dark quote badge graphic.
- `sidebar-quote-light.png`: Light quote badge graphic.
- `dashboard-bg-dark.png`: Background texture for dark dashboard.
- `dashboard-bg-light.png`: Background texture for light dashboard.
